# Farabi vision and product strategy

## North star
An embeddable, open, governed intelligence layer that turns trusted data into interactive analysis and reusable BI artifacts, whether authored manually or generated by agents.

## Product modes
1. **Conventional BI:** semantic datasets, chart and dashboard builder, filters, saved views, sharing, export and scheduling.
2. **Conversational BI:** natural-language intent -> authorized semantic plan -> execution -> chart/A2UI composition with explanations and provenance.
3. **Dynamic-to-static:** review an agent-generated dashboard draft, pin semantic definitions and data dependencies, publish an immutable version, then continue scheduled refresh.
4. **Embedded BI:** Java engine and runtime-neutral contracts exposed to other Andalus applications.

## Ecosystem alignment
- **Toba:** data lake and source access abstraction, initially wrapping Dremio; additional source adapters supported.
- **Tenun:** charts and visualization composition.
- **Batik:** A2UI schema, component rendering and interactive agent outputs.
- **Andalus agents:** planning, explanations, suggested charts, dashboard composition, with explicit execution boundaries.

## Success criteria
No ungoverned query execution; reproducible dashboard artifact manifests; reproducible deployment; provider substitution without engine changes; tenant isolation; measurable query latency, queue health and artifact promotion outcomes.

## Non-goals of foundation PR
Full UI, autonomous agent execution, production multi-worker scheduling, semantic-model management UI, and a finished enterprise control plane.
